# 输入与键位

本文件是电脑版键位、键盘导航范围与触屏输入的现行说明。玩家面同表见 `release/基础操作教学.txt`（该文件的去重由另一批负责，本文件不改它）。

代码真源：`spire-godot/ui/key_bindings.gd`（本地配置与键位页）、`spire-godot/ui/keyboard_input.gd`（UI选择）、`spire-godot/ui/touch_input.gd`（触屏手势）、`spire-godot/ui/drag_targets.gd` 与 `spire-godot/ui/target_queries.gd`（目标事实与高亮）；提交经 `spire-godot/ui/command_router.gd` 收口。

## 1. 设置页与保存

- 设置分为“显示”和“键位”两个页面。键位页支持修改按键、组合键、冲突提示、恢复默认，以及可选的长按0.5秒结束回合。
- Esc 固定用于取消和返回；改键时按 Esc 只取消当前改键。
- 键位保存到独立的 `user://key-bindings.cfg`，不写入游戏存档；显示与画风偏好另存 `display-settings.cfg`。
- Android 继续使用触屏操作，键盘规则不适用。

## 2. 默认按键

| 默认按键 | 操作 |
| --- | --- |
| 1—9、0 | 选择从左到右第1—10张手牌，不立即使用 |
| R | 翻转选中牌／切换选中基础动作；无选择时操作鼠标悬停的卡牌、基础动作或蓄力图标 |
| Space、Enter | 使用选中牌／动作，对当前选定目标结算 |
| Tab、Shift+Tab | 循环选择当前牌／动作的合法目标 |
| E | 结束回合；默认点按，可开启长按 |
| Z、X、V、F | 选择肘击、近身短打、腿部动作、火球术，再确认或点击目标 |
| A、D、C、P | 抽牌堆、弃牌堆、完整卡组、能力区；同键关闭 |
| I、B、S、M、L | 道具、身体与拘束具、状态、地图、行动日志 |
| Esc | 优先取消选择，再关闭窗口，最后打开菜单 |

## 3. 键盘导航规则

- 数字选牌会显示该牌当前效果，合法目标在原区域高亮；目标条可点击确认，箭头与 Tab 用于切换，敌人目标可直接鼠标点击。
- 手牌和常用按钮显示实际绑定按键；输入框保留正常文字输入。
- 弹窗中的键盘确认和焦点移动限制在当前窗口，不触发背景行动；键盘重复事件不连发；丢失焦点会取消结束回合长按。
- 视图版本改变、重开和加载会清除待确认动作。鼠标选择部位后按确认使用最新选中的候选，不另选其他目标。
- 没有键盘专属规则或存档字段：合法目标、高亮与恢复共用 `DragTargets` 与 `TargetQueries` 中的显示事实，支付和规则结果仍由 `main._submit` 完成，右键切换复用原 CardFace 与控件回调。
- 基础动作栏及其切换列表只显示当前姿势允许的形态：连续踢在坐姿出现，横扫在站姿出现；无视姿势的效果沿用规则判定。姿势改变后，已不适用的选中形态回到该类首个可显示形态；能量、次数、冷却和拘束等其他限制仍显示禁用原因。

## 4. 弹窗与奖励界面的焦点范围

- 统一奖励列表、选牌页与 Boss 遗物页共用当前弹窗键盘范围：Tab／Shift+Tab 循环选项，Enter／空格操作选中的原按钮，R 翻转鼠标悬停的奖励卡牌；Esc 先返回奖励列表，不自动领取或跳过。抽屉打开后其键盘范围优先于背后的奖励页。
- 商店付款演出显示时，键盘焦点限制在该演出内：Tab 选择按钮，Enter 或空格沿原控件确认；Esc 和其他快捷键不会打开背后的页面，确认只关闭表现、不重复付款。
- 付款弹窗范围由 `main.modal_region` 共用识别；Android 系统返回键调用该弹窗原确认按钮，优先关闭演出，不打开背后菜单，也不重复付款。

## 5. 卡牌触屏与表现

- 卡牌向下滑动并松手翻面；先确认下滑方向，再达到42个界面逻辑像素的距离才触发。短滑、系统取消、视图版本改变或单面牌不翻面，也不转成点击出牌。上滑及其他拖牌仍走原生拖放。
- 卡牌长按0.5秒查看当前面说明，不翻面。基础动作切换、蓄力图标等非卡牌长按保持原逻辑；滚动抽屉里的非卡牌拖放动作仍可拖向目标。
- 鼠标右键、键盘翻面与触屏下滑复用同一翻面回调。逻辑牌面立即更新，旧面收窄、新面展开只作视觉过渡；动画不提交行动、不改费用或随机。
- 手牌悬停放大预览，保留现有点击使用、键盘确认与快捷解除。拖牌时隐藏原手牌，只显示一张跟随按下位置、适配界面缩放的卡；取消或拒绝后恢复原卡及不可用色调，提交后沿原归堆流程。瞄准线仅消费原生落点的接受结果。无目标／对自身牌拖到手牌上方的战场松手使用，不显示人物目标框或“使用”按钮；拖回手牌区、侧栏或顶部导航取消。需要具体目标的牌仍使用既有身体、装备、敌人或手牌目标，不把多件拘束具擅自合为一个目标。
- 操作方法留在教学与键位页，不在每次悬停、拖动时重复翻面／松手／取消说明。费用、概率、词条与失败原因仍按原入口显示。
- 新表现由 `spire-godot/ui/card_interaction.gd` 维护；预览随离开、销毁或提交清除，拖放随结束或视图版本变化清除；不改变手牌顺序。设置中的“减弱卡牌动效”独立保存，不写游戏存档。

## 6. 检查入口

键盘规则与窗口用例：`tools/check.ps1 -UIOnly -UISuite keyboard`；显示、普通导航、主页和事件窗口分别复用 display／interface／home／events 分类，触屏复用 touch 分类。默认不截图，键位页代表性截图按 `-Screenshots ui-key-bindings.png` 显式生成。命令细则见 `skills/repo-ops/SKILL.md`。

卡牌表现复用 card_interaction 分类：真实鼠标翻面、触屏上下滑、取消、单面牌、非卡牌抽屉拖放、施放区域、逐击日志、施法失败与只读快照检查；安卓原生输入由桌面触屏事件模拟验证，不能据此宣称真机验收。
