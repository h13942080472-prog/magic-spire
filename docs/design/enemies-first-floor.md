# 第一幕敌人真源

本文件是第一幕敌人个体、行动表、生命、后台强度、出场池、意图时机与捕缚来源的唯一真源。“第一幕”指整张塔图，不是地图第1行。捕缚是这些敌人共用的战斗状态，规则与来源数值同在本文件；装备的施加与替换规则见 `./equipment-design.md` §14，奖励与塔路结构见 `./game-design.md` §9，监狱相关数值见 `./prison.md`。

代码真源：`data/enemies.gd`、`data/enemy_library.gd`、`data/first_floor_enemy_pools.gd`、`core/enemy_plans.gd`、`core/guard.gd`、`core/capture_bind.gd`、`core/puppet_enemy.gd`、`core/iron_man.gd`、`data/tower.gd::WEAK_ENCOUNTERS`。

## 1. 分类、强度与共通规则

| 项目 | 规则 |
| --- | --- |
| 分类 | `enemy_library.gd::CLASSIFICATIONS`：弱怪 rope／belt／tape／cable_tie／gag／toybox／lock／small_circle／mixed_bundle／drone；强怪 binding_box／rope_mass／belt_mass／trader／versatile／ominous_circle／rope_serpent；精英 guard／rope_heap／belt_heap／puppeteer；首领 six_bind／iron_man |
| 强度 | 后台正整数（弱怪允许1或2），参与弱池总强度2与强怪组合总强度4预算；不缩放生命、品质、紧度或伤害，不写入玩家视图 |
| 坚硬 | 机械类（`mechanical`）默认受到的非魔法伤害×0.5，魔法与固定伤害正常；体术各段分别结算，群攻逐敌人计算。遗物「破铜烂铁机器人」的覆盖效果见[遗物表](./game-design.md#101-遗物表) |
| 意图 | 视线畅通时公开、眼部受限时隐藏；打断只推迟当前步骤，不消耗步骤、不重抽已准备装备 |
| 饱和与逮捕 | 场上无人形／机械敌人时按饱和离场；有人形／机械敌人且装备空间耗尽时预告逮捕，见 `./game-design.md` §3 |
| 长战斗兜底 | 非Boss战达到回合与拘束门槛后，非人形（含机械）离场，无捕缚机制的人形反复准备逮捕；门槛、计数与结算见 `./game-design.md` §3 |

## 2. 出场池与入场筛选

| 池 | 成员 | 规则 |
| --- | --- | --- |
| 弱池 | rope_solo、belt_solo、tape_solo、cable_tie_solo、gag_solo、toybox_solo、lock_solo、small_circle_solo、mixed_bundle_solo、drone_solo | 按当时真实装备筛选后等权抽取能补齐剩余预算的个体，直到总强度恰好2；漂浮口球、漂浮锁同场各最多1只，其余允许同种重复，可能是一只强度2或两只强度1 |
| 强池 | mass_weak（一团X＋1只强度1弱怪）、four_weak（4只不同类型强度1弱怪）、mixed_pair（两只一团分不清的拘束具）、binding_box_solo、drone_pair、ominous_circle_pair、serpent_weak、versatile_trader | 八个组合总强度均为4，等概率抽取并排除上一场实际遇到的组合；同组换材质或换弱怪不算换组 |
| 精英 | guard_solo、heap_family（一堆X）、puppeteer_solo | 第一幕精英房整池抽取 |
| 塔顶 | six_bind_solo、iron_man_solo | 每周目生成时等权抽取；地图节点及侧栏提前显示已确定的首领名称，详细图与总览均可查看。同周目中途更换地图保留该首领（包括服刑出狱与击败出口守卫返塔）；进入二、三周目重新抽取。双魅魔警卫只保留为练习 |

- 前三次普通战斗使用弱池（`Tower.WEAK_ENCOUNTERS=3`），此后使用强池；出狱重建的塔路从第一场起直接使用强池，见 `./prison.md`。
- 入场筛选：嘴部已占用则不抽口球；没有未锁且可上锁的真实拘束具则不抽漂浮锁；常规材质怪须存在一个初级施加或中级最终附着的合法位置；玩具箱须有一件当前可佩戴的池内装备。严格候选全被排除时只放宽其他条件，仍保留这两条排除。
- 名单在首次进入时冻结到房间 `enemy_members`，使用 `encounter` 随机域；查看、保存、读档与刷新不重抽。`last_strong_group` 跨房、存读档与逃狱重建保留，新局清空。
- 一团X／一堆X在组内以各50%确定绳索或皮带材质，结果写入原 `room_encounters`；练习直接指定材质。

## 4. 弱怪行动

| 敌人 | 行动 |
| --- | --- |
| 常规材质怪（绳索／皮带／胶带／扎带） | ①按自己允许模板与三档添加优先级施加初级、二档装备；②加固同类（优先自身来源；生成意图时无合法加固目标则改选自身已有施加意图，出手时无目标则空过）；③准备最终附着（公开中级二档款式／材质／位置）；④复核后附着中级三档并离场 |
| 漂浮口球 | 准备1/2 → 准备2/2 → 附着中级三档口球并离场；口部容量1，最终执行时已占用即失败离场，不叠加、不替换 |
| 漂浮玩具箱 | 准备（按容量与同类限制从敌人通用初级池随机一件并公开名称）→佩戴→停顿，循环不离场；无合法候选仍按三步推进，出现空位后下次准备重新检查 |
| 漂浮锁 | 预告上锁 → 上锁，循环不离场；只处理已有合法装备，不施加皮带、不加固、不改等级或耐久 |
| 小型魔法阵 | 沿用强怪法阵的3点仪式、装备规格、打断与成长规则；第一步准备，之后正常施加4、7、10……件，不自行离场 |

- 常规材质怪的准备结果随实例冻结；已公开目标失效时只在原模板、品质、材质与紧度内换合法位置，同一身体区域内换子位置也写日志；没有合法位置时普通动作停留、最终附着失败后离场，不覆盖或移除已有装备。
- 皮革眼罩最低中级，因此不进入初级施加，但可进入中级最终附着；布带眼罩不在这些敌人的池中。
- 敌人池（`install_pool`／`final_pool`，出处 `data/enemies.gd::TYPES`）：

| 敌人 | 初始池 | 最终池 |
| --- | --- | --- |
| 漂浮绳索／细绳相关 | rope、cord、合法链接绳 | 同左 |
| 漂浮皮带 | belt、fine_belt、eye_leather | 同左 |
| 漂浮胶带 | tape、eye_tape、mouth_tape | 同左 |
| 漂浮扎带 | cable_tie | cable_tie |
| 漂浮口球 | — | mouth_band（口部，容量1） |
| 玩具箱 | 敌人通用初级特殊池（8件，来源见 `./equipment-design.md` §11） | — |
| 漂浮锁 | 无装备池，只对已有装备上锁 | — |
| 小型魔法阵 | 强怪法阵白名单（普通绳索、细绳、皮带、细皮带、胶带、扎带、皮革眼罩、胶带眼罩、口部胶带、口球与链接绳），每件在初级二档／中级一档中等概率选择 | 同左 |

- 主页“贞操锁池”开启时，漂浮锁在无上锁目标后追加一次离场附加：固定尝试佩戴一件中级三档「负数平板锁」（自动附带加固带），默认上锁，随后离场，不受5%—100%随机池概率影响；同级或更强的平板锁不能被重复／降级替换，附加失败或被闪避仍离场，打断则连同离场一起延后，被击败取消附加。

## 5. 强怪行动

### 5.1 一团X（`rope_mass`／`belt_mass`）

| 步骤 | 行动 |
| --- | --- |
| 1 | 准备：冻结一件中级二档绳索类（皮带）装备及合法位置并公开，本步不安装 |
| 2 | 施加已准备的一件装备（普通件或合法链接绳）；目标失效时按同模板、等级、紧度与原连接规则复核 |
| 3 | 加固自身同类装备；预告时无合法加固目标则改选自身施加意图，出手时无目标则空过；随后继续循环 |

不自行离场。生命降到0时取消未执行计划并生成两只完整生命的同级弱怪（绳→漂浮绳索、皮带→漂浮皮带）；本体分裂与只击败其中一只都不给奖励，全部敌人离场后只结算一次战斗奖励。改数据化的 `cycle`／`install_grade`／`defeat_spawns` 实现，没有强怪专用攻击命令。

### 5.2 一堆X（`rope_heap`／`belt_heap`）

| 步骤 | 行动 |
| --- | --- |
| 1 | 施加“绳索／皮带增生”：从下一玩家回合开始每回合新增一件初级二档同类装备；仅在施加者存活时生效 |
| 2 | 准备 |
| 3 | 在两个不同实际位置各施加一件中级二档同类装备 |
| 4 | 预告时有合法加固目标则预告两次加固；出手时随机两处各加固至三档，不足的次数空过；完全无目标才改选自身施加意图 |
| 5 | 蓄力 |
| 6 | 每个合法位置各新增一件中级三档普通件或合法链接绳；随后按最大生命的50%为基数分裂并移除本体 |

受击后仍存活且生命≤最大生命50%时立即分裂：产生一团绳（继承基数全部生命，保留小数）与两只漂浮绳索（各取一半向上取整），继承值同时作为当前生命与上限；一击降到0优先按普通击败处理、不分裂。提前分裂取消后续行动，不执行第六次全身施加。分裂与击败立即停止增生，已添加装备保留；新敌人当回合不行动。

### 5.3 其他强怪

| 敌人 | 规则 |
| --- | --- |
| 游动的绳蛇 | 循环为缠身→各50%收紧一件绳索至三档或甩缚两件初级二档绳索→缠身。缠身＋1层紧缠；每层在玩家回合结束、敌方行动前施加一件初级二档绳索类装备。生成收紧意图时无目标改甩缚，预告后目标消失则空过；来源死亡立即停止，现有装备保留 |
| 看着不妙的魔法阵 | 首动获得3点仪式，当回合即可增长；自身每个回合末永久＋3施加数量。之后每次施加基础1件＋当前加成（4、7、10……），每件在初级二档／中级一档中等概率选择合法普通装备（白名单同上，含链接绳）；无合法新增位置后把剩余次数逐次转为普通加固，新增与加固都无目标才结束，无替换权限 |
| 一团分不清的拘束具 | 首招固定散缚；之后排除达到连续上限的动作再按权重抽取：散缚（25，上限1，施加2件初级二档）／翻卷收紧（30，上限2，先施加1件再随机加固一件至三档）／躁动膨胀（45，上限1，＋1层永久狂躁，每层让之后每次施加额外＋1件）。预告保存已选动作但冻结具体装备，出手时选定；装备池为全部已启用初级普通模板（含口球），不含复合、特殊装备与布带眼罩；无人形替换权限 |
| 魔导无人机 | 机械类；首动直接施加无人机捕缚30/100，之后循环：处理胶带（等概率施加2件初级一档胶带／累计加固胶带2档；无合法加固目标只选施加）→捕缚＋10→发呆。捕缚期间上身至少1级、立即免费固定为站姿并禁止切换姿势；每累计实际消耗2能量为一个合法位置施加1件初级二档胶带并使共用进度＋10，余数跨回合保存，无可施加位置仍加进度 |
| 魔导拘束盒 | 机械类；第一回合直接施加40/100捕缚，固定坐姿、上身至少1级；施加捕缚后的首个玩家回合不触发，此后每个玩家回合开始抽牌前施加1件中级二档皮革拘束具并使捕缚＋10（无合法位置仍＋10）。归零后准备一回合再施加。捕缚生效后循环：①等概率施加2件中级二档自有池装备或累计加固皮革4档；②准备一回合；③在剩余备用复合装备中随机施加一件，用完后改为捕缚＋10。备用库存三件各一件、均中级二档：上段单腿套、下段单腿套、短型直肩带单手套；成功才消耗，解除并重新捕缚不补货。机械类复合施加获得正式替换权限，普通施加不扩权 |
| 被魔法控制的奴隶贩子 | 人形；首次1→2→3→4，之后循环1→3→4，累计三轮后逮捕。①随机施加2件随机种类初级拘束具（紧度2，不含口球）；②给玩家1层无力化（持续1个玩家回合，禁止基础攻击，不影响魔法、挣扎、滑脱、移动与道具）；③施加1件随机中级拘束具（紧度2）并自身获得1层准备就绪；④优先在中级马具口球与中级皮革眼罩中寻找可施加方案（准备就绪生效时为紧度3），两处均无解时改选本次允许的其他中级普通拘束具／部位，不扩大到复合池。普通白名单为已登记的绳索／细绳／皮带／细皮带／胶带／扎带／胶带眼罩／堵嘴胶带，中级另允许皮革眼罩与口球；含绳索或皮带类时自动获得合法链接候选。准备就绪可叠层，每成功施加或替换一件装备消耗1层并把该件紧度固定为三档 |
| 多面手 | 人形；第1回合发呆，第2回合随机安装一件初级二档性玩具，第3回合在可成立的行动中等概率选择“随机上锁一件可上锁拘束具”或“随机加固至多两件拘束具到三档”，此后第2、3回合循环。分支预告后冻结，具体目标在出手瞬间随机选择，目标不足的次数落空。性玩具安装具有正式人形替换权限；初级池不含飞机杯与 `external_wand_low`，中级池保留 `external_wand_medium` 且不含飞机杯；开启“贞操锁池”后中级池另含两种中级平板锁，锁分支默认25%（可按5%调整），没有合法锁或升级时不掷空、概率完整归还普通性玩具 |

## 6. 精英：魅魔警卫与捕缚

魅魔警卫是成年女性人形精英；单体精英遭遇、双人练习、巡视反抗与监狱出口战共用同一实现。战斗立绘池含紫发与棕发两张用户指定图，每只生成时独立等概率抽取（有放回，双警卫可以同图），使用独立美术随机域。

| 步骤 | 行动 |
| --- | --- |
| 开场1 | 同一次行动在手腕、口部、脚踝各施加一件中级二档拘束具；无法新增或合法替换时改为加固该处1次（紧度3且可上锁时上锁并回满） |
| 开场2 | 准备1回合 |
| 开场3 | 建立警卫捕缚，初始50/100；已有其他种类捕缚时只增加25 |
| 捕缚循环1 | 随机施加2件中级二档普通拘束具 |
| 捕缚循环2 | 捕缚进度＋10 |
| 捕缚循环3 | 随机施加1件中级二档复合拘束具；没有可安装或可替换方案时把至多两件合法拘束具加固到三档，不足次数落空 |

捕缚是独立战斗状态，不占装备容量，上限100。

| 项目 | 共用规则 |
| --- | --- |
| 伤害处理 | 挣扎与滑脱伤害牌可把它当作单独目标：牌面基础、当前力量／灵巧与蓄力全额计入，不计算装备紧度、同层减伤、锁、链接或环境加成；角色除眼罩与口球外没有其他拘束具时最终伤害×2；降紧牌也可选捕缚，每层固定削减8点，多层逐段结算，归零即止；降紧不受属性、蓄力或伤害倍率影响且不消耗蓄力 |
| 来源叠加 | 同种捕缚不可叠加或重复增加进度；不同种类共存并共用一个进度条，新种类只增加自身初始值的一半（无人机30＋警卫50→55；警卫50＋无人机30→65） |
| 进度归零 | 立即解除全部来源及余数；单个来源离场只解除它的效果，仍有其他来源时保留当前进度，最后一个来源离场清空 |
| 出现期间 | 上身束缚等级至少按1级计算；禁止向墙或离墙移动，进度归零或全部来源离场后恢复 |
| 收押 | 达到100后由来源在下一敌方回合预告并执行收押，不打断当前结算；本阶段刚达到100不改写本阶段预告；打断则延期，来源先被击败则取消。任一来源执行成功即整场失败，安全等级只加一次 |
| 清理 | 战斗正常结束或进入监狱时清除捕缚与来源 |

警卫种类生效时的额外效果：姿态路线只允许躺姿→坐姿→站姿（反向与跳级不可用），每次成功切换使进度＋10；玩家每次成功提交一项花费能量的行动，随机牵动一个特殊部位产生10点基础快感（再乘该处敏感度与现有快感倍率，行动中恰好挣开捕缚仍完成本次刺激）；每次高潮使进度＋10。

## 7. 精英：一堆绳、玩偶师

- 一堆绳／一堆皮带：生命96，行动表见 §5.2（六次行动、半血分裂、死亡优先）。
- 玩偶师为人形精英，基础生命见上表。开场自带一只满血人形玩偶（召唤不属于回合行动，战场站位玩偶在左、玩偶师在右）。玩偶出生即有牵线保护：生命最低为1，溢出伤害转给玩偶师，不重复乘算，但受其护身屏障限制。玩偶师被击败后玩偶立即离场并清除效果，整场只发一次精英奖励。
- 护身屏障开场即生效：每个战斗回合的最终伤害上限为30×周目生命倍率，三周目依次30／45／60；单次、多段、多次攻击、遗物及玩偶转移共用额度。下一正式战斗回合开始时重置；查看、选牌、刷新、读档和普通再次攻击均不重置。状态图标显示本回合剩余可受伤害，不显示层数；屏障不因额度用尽而消失。只乘周目倍率，监狱的额外生命不增加额度。
- 玩偶普通反击初始容量3，每次正数受击发动普通反击即消耗1次，未能佩戴或被闪避也不返还；耗尽后不再普通反击，但嘲讽与伤害转移仍生效。当前余量单独保存并显示在容量图标；复合装束和暗藏机关不消耗该容量。
- 伤害严格超过护身屏障剩余额度并被截断时，该玩偶师的玩偶普通反击容量上限－1，最低1；当前余量超过新上限时压至新上限，下降持续本场战斗。刚好打满额度不触发，额度耗尽后继续造成正数伤害仍触发。一次攻击的多段、群体命中及玩偶伤害转移对同一玩偶师最多触发一次；下一次攻击重新计数。容量已为1时不积欠扣减，缝补仍上限＋1并补满。此下限只约束容量上限，反击余量仍可用至0；旧存档曾降至0的容量按1显示，不凭空补余量，下一次缝补按当前上限＋1补满。

| 行动 | 效果 |
| --- | --- |
| T1 引敌缚咒 | 玩偶获得嘲讽与受击反应：单体攻击必须选择玩偶；普通反击尚有余量时，每次受到正数伤害尝试对玩家施加一件初级二档普通拘束具（多段逐段触发，遗物伤害也算，零伤害与施法失败不算） |
| T2 复合装束 | 随机准备一件中级二档复合拘束具，下次攻击命中玩偶时额外对玩家施加 |
| T3 暗藏机关 | 从现有中级特殊装备池随机准备一件三档特殊装备，下次攻击命中玩偶时额外对玩家施加 |
| T4 缝补玩偶 | 玩偶最大生命＋5并恢复至满血；普通反击容量上限＋1并补满 |

之后重复T2→T3→T4。两类额外装束各保存一件，同类未触发时由新的准备替换；下一次攻击的第一段正数命中消耗全部准备，后续段只在尚有容量时继续普通反应；遗物等非攻击伤害不消耗准备。准备时冻结款式，触发时按玩家当时状态使用正式施加入口；无合法位置时本次施加落空，准备仍已消耗。嘲讽只限制单体敌人攻击，群攻照常命中全部存活敌人。

## 8. 塔顶首领

### 8.1 六缚

类型 `six_bind`，基础生命200，后台强度6，成年女性人形首领；遭遇 `six_bind_solo` 与铁男共同进入塔顶首领池，不进入弱怪、强怪或精英随机池。击败后分别领取三选一稀有卡与三选一Boss遗物，完成战后整备才开放出口。

| 自身行动 | 名称 | 效果 |
| --- | --- | --- |
| 1 | 展开六缚阵 | 准备，不施加装备 |
| 2 | 六重束装 | 眼部、口部、双臂、手腕与手部、大腿、小腿与足部六个区域各尝试施加一件初级二档拘束具；再安装一件当前合法的初级性玩具 |
| 循环1、4 | 戏弄封缚 | 施加一件中级二档普通拘束具，并把一张「玩弄」混入本场弃牌堆 |
| 循环2 | 双重束缚 | 施加两件中级二档普通拘束具；缺少合法新增位置的次数转为普通加固 |
| 循环3、6 | 调教升温 | 安装 `1＋当前收束层数` 件当前合法的性玩具，并执行相同次数的普通加固；随后收束＋1 |
| 循环5 | 复合束装 | 尝试施加一件中级二档复合拘束具；无法完成时改为累计加固3档 |
| 循环7 | 六缚齐收 | 再按六个区域各尝试施加一件中级二档拘束具，并混入三张「玩弄+」 |
| 循环8 | 空闲 | 本回合不行动，然后从循环1继续 |

- 八步循环固定为戏弄封缚→双重束缚→调教升温→戏弄封缚→复合束装→调教升温→六缚齐收→空闲（`EnemyPlans.SIX_CYCLE_LENGTH=8`），空闲不施加／加固装备、不加入状态牌、不增加收束。
- 第一轮调教升温使用初级性玩具池，之后使用中级池；随机池排除飞机杯。数量在意图形成时按 `1＋当前收束层数` 冻结，执行完成后才增加收束。
- 性玩具安装使用人形替换权限：同族位置已占用或容量已满时按品质比较与最外层规则替换，同批新装件受保护；普通性玩具不能替换平板锁，只有更高等级或更多功能的平板锁能单向升级，没有合法升级时平板锁分支退出候选并把概率归还普通性玩具。
- 「玩弄」与「玩弄+」不可打出，玩家结束回合时仍在手中分别＋5／＋8快感；每张独立UID并参与牌堆守恒，战斗结束或被收押时清除。
- 高潮逮捕：本场累计第4次高潮时把下一项行动改为“准备逮捕”，此后第5、6、7……次每次高潮各触发一次；该意图进入共用打断入口，任意打断都能取消，取消后六缚不推进当前步骤、下一回合先恢复被插入前的原行动，再从下一次高潮继续检测。未被打断则沿正式收押流程立即结束战斗。装备空间耗尽的普通逮捕与其共用延后规则，见 `./game-design.md` §3。

### 8.2 铁男

遭遇 `iron_man_solo` 由铁男、捕缚无人机与魔导拘束盒组成。画面由左到右为捕缚无人机、魔导拘束盒、铁男，基础生命依次40／40／140。站位由既有 `_battle_scene` 显示排序调整，不改变行动顺序；生命沿 `Enemies → _append_enemies → GameView` 共用通道读取。小魔女进入该遭遇时三者生命额外×1.3，依画面顺序得到52／52／182；普通楼层的无人机与拘束盒数值不变。铁男被击败时，两名随行单位无论剩余生命多少都立即停机。

练习菜单的「铁男练习」直接初始化该完整遭遇，使用所选角色的正常生命倍率、卡组与正式行动规则。铁男也遵循§6的共用捕缚收押规则，不要求进度条中必须已有铁男自身来源。

铁男开场施加30/100捕缚，之后按五步循环行动：

| 循环 | 行动 |
| --- | --- |
| 1 | 捕缚＋10；捕缚已经解除时，改为重新施加捕缚 |
| 2 | 施加2件中级二档普通皮革拘束具；基础加固量为0档 |
| 3 | 施加1件中级二档复合皮革拘束具 |
| 4 | 按当前强化层数佩戴／替换杯具或替代特殊装备，再补满全部特殊装备的电量 |
| 5 | 用本次行动强化捕缚系统，然后从循环1继续 |

- 铁男捕缚强制玩家保持坐姿或躺姿，不能移动。施加捕缚时，普通平板锁及其覆盖范围内可替换的特殊装备会被当前杯具规格替换：初始为中级紧度2「龟头榨精杯」。诅咒平板锁不可替换；佩戴诅咒平板锁或使用小魔女时，改为随机佩戴3件中级紧度2的其他特殊装备。
- 捕缚被移除时，铁男当前强化层数降低1（最低0），撤回对应层的累计效果，后续杯具规格也随之回退；不即时改写身上已佩戴装备。铁男在下一次行动发呆，机械减伤失效2回合；发呆不推进五步循环。
- 铁男自身捕缚单独累计耗能：玩家每累计消耗5能量，身上全部仍有电量的主动刺激型特殊装备各结算一次；余数跨玩家回合保留，与无人机分别计数。
- 本场的凑数型无人机独立施加初始20捕缚，拥有自己的耗能累计；每累计消耗3能量，施加1件初级紧度2胶带拘束具（含眼罩与嘴部胶带候选）、捕缚＋5、随机遥控1件主动刺激型特殊装备并使该装备电量－1，再随机给1件可上锁的拘束具上锁。敌方回合仅开场施加捕缚、解除后准备并重施；捕缚有效时待机，不额外重复耗能效果。
- 本场实例命名为「凑数型拘束盒」「凑数型无人机」。拘束盒生命40、初始捕缚20；其循环行动1改为施加2件中级1档皮革／口球，或累计加固2档；回合开始及备用复合装备耗尽后的捕缚追加均为＋5，其他施加与复合库存保持原规则。普通遭遇中的拘束盒仍为初始40捕缚、2件中级2档／加固4档、追加＋10；普通魔导无人机保持原规则。
- 开场三者依次施加捕缚，初始共用进度为30＋20÷2＋20÷2＝50。拘束盒施加捕缚后的首个玩家回合跳过装备施加与进度追加，因此玩家接手时保持50；再下一回合恢复触发。普通拘束盒同样跳过，解除后重新施加也重新跳过一次。

每次第五步强化使当前强化层数＋1，重新施加捕缚的初始值按当前层数每层＋5，并按下表依次获得一组累计升级；第四组后从第一组继续。普通／复合施加共用安装声明，允许合法替换；剩余无法施加的次数转为既有普通拘束具加固：

| 强化组 | 累计效果 |
| --- | --- |
| 1 | 此后施加的全部拘束具紧度＋1；普通拘束具数量＋1；加固量＋2档 |
| 2 | 此后施加的全部拘束具等级＋1；普通拘束具数量＋1；加固量＋2档 |
| 3 | 复合拘束行动额外施加1件高级紧度3特殊装备，并额外随机上2把锁 |
| 4 | 普通拘束具数量＋1；特殊装备数量＋1；加固量＋2档；上锁数量＋1 |

杯具规格按当前强化层数累计：0层为中级龟头杯、紧度2；1层升级为中级全包杯、紧度2；2层紧度升为3；3层升级为中级马眼全包杯、紧度3；4层升级为高级马眼全包杯、紧度3；5层及以后杯具无额外变化。强化本身更新下次施加规格，开场／重新捕缚及补电行动通过同一杯具入口应用；杯具仍最多1件，无法佩戴杯具时（诅咒平板锁或小魔女），开场／重新捕缚和补电都走同一替代施加流程，按当前规格请求新增／合法替换：0层3件中级紧度2；1层升为紧度3；2层数量＋1（4件）；3层升为高级；4层及以后每层再增加1件。替代分支不应用杯具的型号升级。解除捕缚降层时，替代数量／品质／紧度按当前层数同步回退。

## 9. 续局血量与生命缩放

- 抵达出口后选择“继续游玩”（最多三轮）：怪物生命按正常基础值乘1／1.5／2，六缚为200／300／400，铁男为140／210／280；所有敌人出生点共用倍率，包括自定义基础生命与召唤物。小魔女的铁男专属×1.3系数先作用于该遭遇三名成员，再与续局倍率相乘。
- 分裂继承的血量已包含倍率，只按原比例计算，不再乘一次；玩偶缝补等固定生命增量仍使用原值。
- 入狱加成在周目倍率之后叠加：`(警戒度−1)×普通10／精英20／Boss30`，同场召唤沿该场类型加成，分裂继承不重复添加；监狱守卫生命不变。出处 `core/prison.gd::health_bonus`。

## 10. 意图生成与出手时机

- 加固意图不指定具体目标。没有明确声明指定目标的施加类行动只在敌人实际出手时按玩家当时状态寻找目标；预告可以确定行动种类、数量、品质、紧度与装备池，不提前抽取具体装备或部位目标，除非该行动明确声明提前准备某件具体装备。
- 生成加固意图时只检查是否存在合法加固目标；没有就从该敌人本来拥有的施加拘束具意图中随机选一个作为预告（保留其数量、池、等级与紧度），之后继续原行动序列；完全没有这类意图则空过，不补造能力。
- 已预告的加固在出手时再次检查：仍有任一合法目标就按当前规则选取并加固，全部无目标则本次空过、消耗该次行动并推进行动步骤，不改成临时施加；批量加固的缺额同样空过。
- 玩家只解除一件并不保证加固落空，需要让出手时全部合法加固目标消失；加固者不能加固最高档装备或不支持通用加固的特殊装备。
- 明确指定目标或提前准备具体装备的行动保留其专门声明。特殊装备有“拘束具”词条，但其可加固、可锁、可替换资格仍读自身规则。
- 正式实现：`EnemyPlans.resolve` 在正式敌方操作时调用，预览与读档不重抽。

## 11. 实现入口

- `data/enemies.gd`：个体、后台强度、装备池与遭遇表。
- `data/enemy_library.gd`／`data/first_floor_enemy_pools.gd`：分类与第一幕池。
- `core/enemy_plans.gd`：准备、循环、目标复核、持续施加。
- `core/guard.gd`：警卫序列、附加行动与收押准备。
- `core/capture_bind.gd`：捕缚进度、来源、姿态与触发结算。`allowed_postures` 是来源姿态交集的唯一查询，`fixed_posture` 消费其结果决定是否需要固定／校正；候选拒绝与状态校验复用同一交集。`apply_bind`／`observe` 沿原入口落地姿态，查询结果不跨调用缓存。
- `core/puppet_enemy.gd`：玩偶师的玩偶转移、准备与嘲讽。
- `core/iron_man.gd`：铁男循环、强化、捕缚装备、耗能刺激与随行单位联动。
- `core/game.gd`：共用随机施加、特殊装备资格／安装与正式敌方回合执行；`core/snapshot.gd` 冻结计划的结构校验与恢复；`core/intent_view.gd`、`data/glossary.gd`、`ui/combat_feedback.gd` 负责意图、解释与实际结果展示。
